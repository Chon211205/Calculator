# Calculadora React, proyecto 2

Calculadora hecha con React, TypeScript, Vite y Bun. Permite realizar suma, resta,
multiplicacion, division, modulo, punto decimal y cambio de signo.

## Enlace al link: https://joelsiervas.online/241203/calculadora/

## Requisitos

- Bun instalado

## Instalacion

```bash
bun install
```

## Correr la aplicacion

```bash
bun run dev
```

Luego abrir la URL que muestra Vite en la terminal.

## Correr tests

```bash
bun test
```

Tambien funciona con:

## Correr lint

```bash
bun run lint
```

## Correr Storybook

```bash
bun run storybook
```

Storybook corre normalmente en:

```text
http://localhost:6006
```

## Crear build de produccion

```bash
bun run build
```

El resultado se genera en la carpeta `dist`.
